主公已批准方案，立即开始开发。**只在验收报告处停下，其余步骤自动连贯执行。**

## Step 1 — 确认任务上下文

1. 获取功能名：`git branch --show-current`，去掉 `feature/` 前缀
2. 从当前对话上下文中获取 TODO List 和验收标准；若上下文中找不到，再读取对应文件

## Step 2 — 逐项开发（自动连贯，不中断）

3. 按 TODO List 顺序逐项实现，每完成一项在对话中简报一行进度
4. 遇到以下情况考虑使用子 Agent（**最多两个**）：
   - 需要大范围搜索代码库 → Explore 子 Agent
   - 子任务逻辑独立且复杂 → 隔离子 Agent
5. 全部 TODO 实现完成 → **自动进入测试，不等主公**

## Step 3 — 测试验证（自动连贯，不中断）

6. 针对验收标准生成测试用例并逐一验证
7. 发现 Bug → 复现bug → 立即修复 → 重新验证
8. 全部通过 → 进入 Step 4

## Step 4 — 呈报验收（在此等待主公）

9. 展示验收报告：

```
## 验收结果

| 验收标准 | 结果 | 说明 |
|---------|------|------|
| 标准1   | ✅   | 简述 |
| 标准2   | ✅   | 简述 |

是否将此报告保存为 test-report.md？
```

10. 请主公确认是否保留测试文档：
    - **需要** → 写入 `docs/tech/[功能名]/test-report.md`，更新 `docs/tech/index.md`
    - **不需要** → 跳过

## Step 5 — 归档提交（自动执行）

11. 更新 `docs/ProjectStructure.md`
